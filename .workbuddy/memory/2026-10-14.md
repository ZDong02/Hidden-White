# 第三轮修正：/api/api/health 404（自身引入的 bug）

## 现象
小程序控制台：`GET http://10.30.120.150:8080/api/api/health 404`

## 根因（自己写的代码缺陷）
`config/backend.js` 中 `HEALTH_PATH` 写成了 `'/api/health'`，
而 base 地址已被 `ensureApiSuffix()` 补上 `/api` 后缀，
两段拼接就成了 `/api` + `/api/health` = `/api/api/health` → 404。
真实后端路径是 `/api/health`（`HealthController`：`@RequestMapping("/api")` + `@GetMapping("/health")`）。

## 修复
- `HEALTH_PATH` 由 `'/api/health'` 改为 `'/health'`（相对路径，因为 base 已含 `/api`）。
- `ensureApiSuffix()` 加固：先 `replace(/\/api$/i,'')` 去掉可能重复的 `/api`，
  再补一个 `/api` → 结尾恰好一个 `/api`。
  这样用户手填 `http://IP:8080`、`.../`、`.../api`、`.../api/` 都能归一。

## 验证
- eslint 通过；`build:mp-weixin` 通过。
- 产物校验：`backend.js` 中 `/api/api` 出现次数为 0，`s="/health"`。
- 逻辑单测：4 种手动输入形态 + 3 个候选地址拼接结果均正确。
- `curl /api/health` → `{"status":"UP"}`。

## 教训
base 与 path 拼接时，path 必须用**相对路径**，
否则两边各自含 `/api` 就会重复。此类拼接建议在写完立刻用真实请求验证一次。

# 第四轮：card 组件 3D 倾斜 + 径向流光 + Spring 阻尼

## 设计定调
沿用隐白既有「墨黑 #030303 × 香槟金 #d4ad2f」轻奢语言。倾角刻意压到 8°（远低于常见的 15–20°），
高光用「金色薄雾 + soft-light 混合」而非塑料感白光。深色卡（会员卡/进度卡）改用 screen 混合 + 更亮暖金。

## 新增文件
- `utils/tiltCard.js`：核心。指针偏移→rotateX/rotateY 插值、径向流光、Spring 阻尼回弹。
  单例 rAF 循环驱动所有实例（避免每卡一个循环）；pointer/touch 事件统一入口；
  `prefers-reduced-motion` 下直接关闭全部动效。
- `utils/useTiltCard.js`：单卡片场景封装（会员卡、取餐卡、进度卡等）。
- `utils/useTiltList.js`：列表场景封装，控制器与矩形缓存按索引管理，处理器对象按索引缓存。

## 参数（经数值仿真调优，勿随意改）
- `maxTilt: 8`（度）— 8° 是高级感与可读性的平衡点，>12° 显廉价且文字变形。
- `perspective: 900`（px）— 800–1000 接近真实卡片俯视感。
- `follow: 0.18` — 实测 0.2s 到达 90%，且已做帧率归一化（30fps 与 120fps 耗时几乎一致）。
- `spring.stiffness: 0.18` / `spring.damping: 0.42` — **关键修正**：
  最初用 0.085/0.78，仿真发现**完全无过冲**（单调收敛，手感发死）且耗时 1s。
  调优后过冲约 1°、0.43s 收尾。damping 必须 < 1（临界阻尼）才有弹性。
- `glareOpacity: 0.13`、`glareSize: 260px`。
- 倾角映射：rotateY = offsetX * maxTilt，rotateX = -offsetY * maxTilt。

## 踩坑记录（重要）
1. **小程序端不支持 `v-bind="对象"` 展开** —— 编译报 `[vite:vue] v-bind="" is not supported`。
   必须改为具名处理器：`@touchstart="bind.enter" @mousemove="bind.move" @touchend="bind.leave"` 等。
2. **animation 终态会覆盖内联 transform** —— 原 `@keyframes card-enter` 带 `transform: translateY()`
   且 `both` 保留终态，会让 3D 倾斜完全失效。已改为纯 opacity 入场。
3. **transform 会成为 fixed 后代的包含块** —— 项目 `common.scss` 早有此注释。
   已确认所有 card 内部无 `position:fixed`（fixed 只在 `.bottom-fixed` 弹窗与底栏），安全。
4. **perspective 必须写在同一个 transform 内**且置于最前，否则 3D 变换不生效。
5. 深色卡的流光需 `mix-blend-mode: screen` 而非 soft-light，否则拉不出金属反射。

## 接入范围（7 类卡片）
首页 `.product-card`、会员页 `.member-card` + `.benefit-card`(4张)、
订单页 `.progress-card` + `.history-card`、结算页 `.pickup-card`、
个人中心 `.member-card` + `.orders-card` + `.service-card`。
全局基座（`.tilt-card` / `.tilt-glare` / `.tilt-body`）统一放在 `styles/common.scss`。

## 无障碍
- 可点击卡片加 `role="button"` + `tabindex="0"`，共 7 处。
- `:focus-visible` 提供 2px 香槟金焦点圈（outline 不触发布局）。
- 键盘聚焦时 JS 施加固定轻微倾斜（-0.28）并显示流光，离开同样走 Spring 回弹，
  使键盘用户无需鼠标也能感知卡片已激活。
- `prefers-reduced-motion: reduce` 下关闭全部过渡与变换，仅保留静态描边反馈。

## 验证
- `npx eslint pages/ utils/ components/` 通过。
- `npm run build:mp-weixin` 与 `npm run build:h5` 均构建成功。
- 产物核验：wxml 含 bindtouchstart/move/end；app.wxss 含 tilt-card / tilt-glare 基座与 reduced-motion 规则；
  tiltCard.js 含 perspective 注入与 spring 参数（stiffness:.18）。

# 第五轮：清除 card 3D 倾斜（回退第四轮）

## 结论（重要教训）
**uni-app 小程序端不能依赖 `requestAnimationFrame` 做 JS 驱动动画。**
