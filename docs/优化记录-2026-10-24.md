## 二、优化清单

### 1. 验证码服务端渲染（安全）

`CaptchaService.generate()` 不再返回明文 `code`，改为返回 `uuid + image`（116×42 SVG data URI，字符随机旋转 + 干扰线）。管理端登录页改为渲染 `<img>`，前端类型 `CaptchaResponse` 同步调整。新增 `CaptchaServiceTest` 3 例：响应不含明文、图内字符与存储值一致（可验证通过）、取出即失效语义。

### 2. 认证入口 IP 限流（安全）

新增 `RateLimitFilter`（`OncePerRequestFilter`，order 紧随 TraceIdFilter）：对 `/api/auth/login`、`/api/auth/register`、`/api/admin/auth/login`、`/api/admin/auth/captcha` 四个免登录入口按 IP 滑动窗口限流（默认 30 次/分钟，可按构造参数调整），超限返回与 `R` 同构的 429 JSON。关键取舍：

- **不解析 `X-Forwarded-For`**（可伪造，直连暴露时可随意轮换绕过）；反代部署时用 `server.forward-headers-strategy` 让容器解析受信头
- 内存上界 1 万 IP，触顶对陌生 IP fail-open——限流是加固，不能反过来打挂正常门店
- 定时回收整窗静默的 IP 键，长期运行不泄漏

新增 `RateLimitFilterTest` 4 例：满额即 429、窗口滑动恢复、IP 相互独立、非认证路径旁路。

### 3. 管理端依赖漏洞清零

`npm audit fix`（vue 3.5.35→3.5.44 修复 XSS（GHSA-g2v6-rqmx-r4w6），postcss / nanoid / source-map-js 等同步升级），生产依赖 **0 漏洞**（原 5 high）。升级后 35 例测试 + vue-tsc + 构建全绿。

### 4. 依赖更新自动化

新增 `.github/dependabot.yml`：maven（后端）、npm（管理端 / 点单端）、github-actions 四个 ecosystem，每周检查。点单端的 `@dcloudio/*` / `vue` / `vite` 显式 ignore major 升级——uni-app 工具链锁定在 alpha 快照，升级必须单独立项人工验证。

### 5. 点单端 package.json 规范化

补 `"type": "module"`（`.cjs` 脚本不受影响，`vite.config.js` / `main.js` 本就是 ESM），消除每次 `npm test` 的 MODULE_TYPELESS 重解析警告；顺带修复 scripts 块错乱缩进。

### 6. 管理端品牌文案

`APP.name`「通用后台管理系统」→「隐白咖啡 · 管理端」，`subtitle` / `copyright` 同步；登录页与浏览器标题随之生效。

### 7. 清理

删除仓库根 `data/`（3 张历史商品图副本，逐一 md5 校验与 `HiddenWhite-backend/data/uploads` 一致后删除；该路径本就在 `.gitignore`，属本地遗留）。
