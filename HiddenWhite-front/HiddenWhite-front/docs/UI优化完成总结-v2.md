- ✅ 背景：无 → **毛玻璃效果** (backdrop-filter: blur(12rpx))

- ✅ 切换时长：380ms → **340ms**

### 第三阶段：UI 动效增强

#### 1. 微交互动效
**按钮弹性反馈**：
```scss
// 弹性缓动曲线
transition: transform 120ms cubic-bezier(0.34, 1.4, 0.64, 1);

// 按压
transform: scale(0.96);  // 从 0.975 加大
```

**数字跳动**：
```scss
0%: opacity 0.3, translateY(-8rpx) scale(0.9)
60%: scale(1.06)  // 过冲
100%: translateY(0) scale(1)
```

**骨架屏掠光**：
```scss
// 1.4s → 1.6s，亮度 0.7 → 0.8
animation: sweep 1.6s ease-in-out infinite;

// 新增透明度变化
0%, 100%: opacity 0
50%: opacity 1  // 中段最亮
```

#### 2. 组件动效优化
- ✅ **Stepper 步进器**：
  - 按压：scale(0.88)，弹性曲线
  - 悬停：scale(1.08) + 阴影
  
- ✅ **Modal 弹窗**：
  - 标题字号：32rpx → **38rpx**
  - 内边距：32/24rpx → **40rpx**
  - 入场动画：220ms + 弹性曲线
  
- ✅ **加购按钮**：
  - 按压：scale(0.86)，更大压缩感
  - 悬停：scale(1.08)
  
- ✅ **购物车条**：
  - 入场：translateY(20rpx) + scale(0.98)
  - 数字跳动：280ms 弹性曲线

#### 3. 动效时长统一
| 场景 | 时长 | 缓动曲线 |
|------|------|----------|
| 按压反馈 | 120ms | `cubic-bezier(0.34, 1.4, 0.64, 1)` |
| 颜色过渡 | 180ms | `ease` |
| 位移动画 | 300ms | `ease-out` |
| 场景切换 | 600ms | `ease-out` |
| 轮播切换 | 340ms | `easeOutCubic` |
| 数字跳动 | 280ms | 弹性曲线 |
| 骨架屏 | 1600ms | `ease-in-out` |
