# 点单端 UI 优化更新日志 v2.0

- **版本号**：v2.0
- **发布日期**：2026-10

## 🎨 主要变更

### 轮播图全面提升

#### 视觉增强
- **标题字号**：44rpx → 68rpx (+55%)，支持两行显示
- **副标题字号**：22rpx → 28rpx (+27%)
- **眉标强化**：字重600 + 大写 + 字距4rpx + 发光效果
- **价格字重**：600 → 700
- **背景渐变**：双色 → 四色渐变（135deg）
- **金色光晕**：左上角装饰（opacity 0.6）
- **图片阴影**：内外双层阴影增强边框感
- **图片效果**：边缘径向渐隐融入背景
- **品牌环**：双环效果（内描边 + 外发光）

#### 交互优化
- **切换时长**：380ms → 340ms (-11%)
- **按压反馈**：scale(0.985) + translateY(2rpx) 下沉感
- **悬停效果**：图片放大1.04x，链接右移4rpx

#### 指示点重设计
- **位置**：左下角 → 底部居中
- **尺寸**：8/28rpx → 10/32rpx
- **间距**：8rpx → 12rpx
- **背景**：新增毛玻璃（backdrop-filter: blur(12rpx)）
- **激活效果**：双层发光阴影

### 排版布局优化

#### 间距语义化（新增6个变量）
```scss
$sp-section: 56rpx;   // 区块之间
$sp-block: 32rpx;     // 内容块之间
$sp-group: 24rpx;     // 相关元素组
$sp-inline: 16rpx;    // 行内元素
$sp-tight: 12rpx;     // 紧凑场景
$sp-optical: 4rpx;    // 光学对齐
$gutter-sm: 32rpx;    // 紧凑留白
```

#### 卡片内边距增加
- **浅色卡片** `.card`：32rpx → 40rpx (+25%)
- **深色卡片** `.card-dark`：40/32rpx → 56/40rpx (+40%/+25%)
- **商品卡片** `.product-card`：24rpx → 32rpx (+33%)

#### 页面节奏优化
- **品牌行下方**：32rpx (保持)
- **门店下方**：32rpx (保持)
- **轮播下方**：0 → 56rpx (新增)
- **分类上方**：40rpx → 56rpx
- **分类下方**：32rpx (保持)

#### 装饰元素
- 品牌区左上角金色光晕（radial-gradient）

### UI 动效增强

#### 微交互动效
**按钮弹性反馈**：
```scss
transition: transform 120ms cubic-bezier(0.34, 1.4, 0.64, 1);
transform: scale(0.96);  // 从 0.975 加大
```

**数字跳动过冲**：
```scss
0%:   opacity 0.3, translateY(-8rpx) scale(0.9)
60%:  translateY(0) scale(1.06)  // 过冲
100%: translateY(0) scale(1)
```

**骨架屏掠光**：
```scss
// 时长 1.4s → 1.6s
// 亮度 0.7 → 0.8
// 新增中段最亮效果
```

#### 组件动效优化
- **Modal 弹窗**：标题38rpx，内边距40rpx，入场220ms
- **Stepper 步进器**：按压scale(0.88)，悬停scale(1.08)
- **加购按钮**：按压scale(0.86)，悬停scale(1.08)
- **购物车条**：入场带缩放scale(0.98)

#### 动效时长统一
```scss
按压反馈: 120ms  cubic-bezier(0.34, 1.4, 0.64, 1)
颜色过渡: 180ms  ease
位移动画: 300ms  ease-out
场景切换: 600ms  ease-out
轮播切换: 340ms  easeOutCubic
数字跳动: 280ms  弹性曲线
骨架屏:  1600ms  ease-in-out
```
