## 二、详细改动清单

### 2.1 轮播图全面提升

#### ✅ 视觉层次增强

**问题诊断**：
- 轮播卡片较平面，缺少深度感
- 图片与文字视觉分离度不够
- 深色背景氛围感偏弱

**优化方案**：

1. **背景渐变增强**
   ```scss
   // 从双色渐变升级为四色渐变
   background: linear-gradient(
     135deg, 
     #29261d 0%,    // 左上高光
     #171713 40%,   // 中部主色
     #241f15 75%,   // 右下过渡
     #0b0a07 100%   // 最深
   );
   ```

2. **左上角金色光晕**
   ```scss
   &::before {
     background: radial-gradient(
       circle at 80% 20%,
       rgba(212, 173, 47, 0.15) 0%,
       transparent 60%
     );
     opacity: 0.6;
   }
   ```

3. **图片容器阴影增强**
   ```scss
   box-shadow: 
     inset 0 0 0 1rpx rgba(212, 173, 47, 0.08),  // 内描边
     0 8rpx 24rpx rgba(11, 10, 7, 0.4);          // 外阴影
   ```

4. **图片边缘渐隐效果**
   ```scss
   &::before {
     background: radial-gradient(
       ellipse at center,
       transparent 30%,
       rgba(11, 10, 7, 0.3) 100%
     );
   }
   ```

5. **品牌环双环效果**
   ```scss
   box-shadow:
     inset 0 0 0 1rpx rgba(212, 173, 47, 0.1),
     0 0 40rpx rgba(212, 173, 47, 0.1);
   ```

#### ✅ 交互体验优化

1. **切换时长优化**
   - 从 380ms → 340ms
   - 更跟手的滑动体验

2. **按压反馈增强**
   ```scss
   &--press {
     transform: scale(0.985) translateY(2rpx);  // 增加下沉感
   }
   ```

3. **悬停动效**
   ```scss
   // 图片放大
   .hero-image { transform: scale(1.04); }
   
   // 链接右移（暗示可点击）
   .hero-link-row { transform: translateX(4rpx); }
   ```

#### ✅ 信息传达优化

1. **标题字号提升**
   - 从 44rpx → **68rpx**
   - 从单行省略号改为最多两行显示
   - 字重从默认改为 500（宋体大字号更优雅）

2. **副标题可读性增强**
   - 从 22rpx → 28rpx
   - 行高从 1.5 → 1.6
   - 增加 opacity: 0.95 柔和视觉

3. **眉标强化**
   - 字重增加到 600
   - 字距从 2rpx → 4rpx
   - 拉丁文字大写
   - 文字发光效果：`text-shadow: 0 0 16rpx rgba(212, 173, 47, 0.4)`

4. **价格字重提升**
   - 从 600 → **700**
   - 数字更醒目

#### ✅ 指示点重新设计

**改动点**：
- **位置**：从左下角 → 底部居中
- **尺寸**：非激活 8rpx → 10rpx，激活 28rpx → 32rpx
- **间距**：从 8rpx → 12rpx（更易点击）
- **背景**：新增毛玻璃效果
  ```scss
  padding: 8rpx 24rpx;
  background: rgba(11, 10, 7, 0.4);
  backdrop-filter: blur(12rpx);
  ```
- **发光**：激活点双层阴影
  ```scss
  box-shadow:
    0 0 8rpx rgba(212, 173, 47, 0.6),
    0 0 16rpx rgba(212, 173, 47, 0.3);
  ```

### 2.2 字体体系精细化

#### ✅ 字号梯度优化

| 原值 | 新值 | 变量名 | 提升原因 |
|------|------|--------|----------|
| 22rpx | **24rpx** | `$fs-micro` | 微小字号在深色背景可读性弱 |
| 26rpx | **28rpx** | `$fs-body-sm` | 与正文档位拉开 |
| 28rpx | **30rpx** | `$fs-body` | 正文基准提升 |
| 30rpx | **32rpx** | `$fs-title-sm` | 小标题层级调整 |
| 32rpx | **34rpx** | `$fs-title` | **新增档位**，填补 32→36 跳跃 |
| 36rpx | **38rpx** | `$fs-title-lg` | 卡片标题微调 |
| 44rpx | **46rpx** | `$fs-h2` | 页面主标题微调 |
| 56rpx | **58rpx** | `$fs-h1` | 品牌字微调 |
| 62rpx | **64rpx** | `$fs-brand` | 登录页品牌字 |
| 64rpx | **68rpx** | `$fs-display` | 展示字更大胆 |
| 132rpx | **136rpx** | `$fs-ticket` | 取餐号微调 |
| 112rpx | **116rpx** | `$fs-splash` | 开屏品牌字微调 |

**优化效果**：
- 填补档位跳跃，视觉节奏更和谐
- 最小字号不低于 24rpx，确保可读性
- 展示字更大胆（68rpx），强化视觉冲击力

#### ✅ 字重体系完善

新增字重变量规范：
```scss
$fw-light: 300;     // 仅超大展示字的装饰性文字
$fw-normal: 400;    // 正文默认
$fw-medium: 500;    // 小标题、强调文字
$fw-semibold: 600;  // 卡片标题、区块标题、按钮
$fw-bold: 700;      // 页面主标题、数字强调（价格）
```

**应用调整**：
- 品牌标题："隐白" 字重 → 600
- 价格字重：600 → **700**（购物车、商品卡片、轮播）
- 轮播标题：宋体大字号用 500 更优雅

### 2.3 排版布局优化

#### ✅ 间距语义化

新增语义化变量，让间距用途一目了然：

```scss
$sp-section: 56rpx;   // 区块之间（轮播与分类）
$sp-block: 32rpx;     // 内容块之间（品牌行与门店）
$sp-group: 24rpx;     // 相关元素组（图片与标题）
$sp-inline: 16rpx;    // 行内元素（图标与文字）
$sp-tight: 12rpx;     // 紧凑场景（指示点间隙）
$sp-optical: 4rpx;    // 光学对齐微调
```

#### ✅ 首页纵向节奏优化

| 区块 | 原间距 | 新间距 | 变量名 |
|------|--------|--------|--------|
| 品牌行下方 | 32rpx | 32rpx | `$sp-block` |
| 门店下方 | 32rpx | 32rpx | `$sp-block` |
| **轮播下方** | **0** | **56rpx** | `$sp-section` ✅ 新增 |
| 分类上方 | 40rpx | 56rpx | `$sp-section` |
| 分类下方 | 32rpx | 32rpx | `$sp-block` |

**优化效果**：轮播与分类之间增加呼吸空间，视觉节奏更舒缓

#### ✅ 卡片内间距优化

| 卡片类型 | 原值 | 新值 | 提升 |
|----------|------|------|------|
| 浅色卡片 `.card` | 32rpx | **40rpx** | +25% |
| 深色卡片 `.card-dark` | 40rpx 32rpx | **56rpx 40rpx** | 纵向+40% |
| 商品卡片 `.product-card` | 24rpx | **32rpx** | +33% |

**图片与文字间距**：
- 商品卡片：24rpx → **32rpx**
- 价格行上方：24rpx → **32rpx**

#### ✅ 品牌区装饰光晕

新增左上角金色渐变光晕，增强氛围感：
```scss

    circle,
    rgba(212, 173, 47, 0.06) 0%,
    transparent 70%
  );
```

### 2.4 UI 动效体系

#### ✅ 微交互动效

**1. 按钮弹性反馈**
```scss
// 使用弹性缓动曲线
transition: transform 120ms cubic-bezier(0.34, 1.4, 0.64, 1);

// 按压缩放增大
&--press { transform: scale(0.96); }  // 从 0.975 加大
```

**2. 数字跳动优化**
```scss
@keyframes number-pop {
  0% {
    opacity: 0.3;  // 从 0.4 降低，对比更强
    transform: translateY(-8rpx) scale(0.9);  // 增大幅度
  }
  60% {
    transform: scale(1.06);  // 新增：过冲效果
  }
  100% {
    transform: translateY(0) scale(1);
  }
}
```

应用场景：
- 购物车数量变化
- 价格更新
- 统计数字变化

**3. 骨架屏掠光增强**
```scss
// 从 1.4s 放慢到 1.6s
animation: sweep 1.6s ease-in-out infinite;

// 亮度从 0.7 提升到 0.8
background: linear-gradient(90deg, transparent, rgba(255, 255, 255, 0.8), transparent);

// 新增：透明度变化（中段最亮）
@keyframes sweep {
  0%, 100% { opacity: 0; }
  50% { opacity: 1; }
}
```

#### ✅ 动效时长统一

| 场景 | 时长 | 缓动曲线 |
|------|------|----------|
| 按压反馈 | 120ms | `cubic-bezier(0.34, 1.4, 0.64, 1)` 弹性 |
| 颜色过渡 | 180ms | `ease` |
| 位移动画 | 300ms | `ease-out` |
| 场景切换 | 600ms | `ease-out` |
| **轮播切换** | **340ms** | `easeOutCubic` |

## 四、技术细节

### 4.1 性能优化

**保持原有性能优势**：
- 轮播懒加载机制不变
- 触摸暂停自动播放不变
- `prefers-reduced-motion` 适配不变

**新增优化**：
- 动效仅使用 `transform` + `opacity`（GPU 加速）
- 避免 `filter`（小程序性能差）
- `backdrop-filter` 仅用于装饰性元素

### 4.2 兼容性处理

**小程序**：
- 所有动效使用 `transform` + `opacity`
- 不使用 CSS 变量（继承行为有版本差异）
- SCSS 变量编译期展开（100% 兼容）

**H5**：
- 悬停态用 `#ifdef H5` 隔离
- 桌面端响应式布局不变
- `prefers-reduced-motion` 自动降级

### 4.3 向后兼容

**渐进增强**：
- `backdrop-filter` 不支持时退化为纯色背景
- 文字发光 `text-shadow` 不支持时仍可阅读
- 所有动效失效时界面仍然可用
